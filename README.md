# Algo Lab به فارسی

کلون فارسی [Algo Lab](http://byte-sized-algorithms.vercel.app) — آموزش ساختمان داده و الگوریتم، قدم‌به‌قدم.

- **نسخه‌ی زنده:** https://ahurabyte.github.io/algo-lab-fa/
- **اصل (انگلیسی):** http://byte-sized-algorithms.vercel.app — ساخته‌ی [Dilum Sanjaya](https://x.com/DilumSanjaya)

## چی داخلشه؟

- ۸۶ درس در ۱۴ فصل: از Big-O و Memory & Pointers تا Graph ،Sorting ،Dynamic Programming و P vs NP
- هر درس چند قدم دارد؛ با دکمه‌های Back/Next و کلیدهای ← → می‌شود قدم‌ها را عوض کرد
- نمودارهای متحرک: مثلاً در Big-O با بزرگ شدن n، تعداد قدم‌های O(1) تا O(n²) عوض می‌شود
- جستجوی کل دوره با Ctrl+K، تم روشن و تیره، پیگیری پیشرفت (0 / 86)
- ۴ درس اول فصل Foundations با متن کامل؛ بقیه‌ی درس‌ها با چیدمان کامل درس در فهرست و جستجو هستند

## ترجمه

رابط کاربری و متن آموزشی به فارسی ترجمه شده و صفحه راست‌چین (RTL) است؛ فونت Vazirmatn.
نام الگوریتم‌ها و درس‌ها (مثل Big-O ،Merge Sort ،BFS)، نمادهای پیچیدگی (O(1) تا O(n²))،
اصطلاحات تخصصی و همه‌ی کدها و Pseudocode ها به انگلیسی مانده‌اند.

## اجرا

فقط `index.html` را در مرورگر باز کنید؛ بدون بیلد و بدون سرور کار می‌کند.
